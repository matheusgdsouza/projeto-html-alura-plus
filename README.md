# 📌 Projeto HTML & CSS – Alura Plus

## 🧠 Sobre o Projeto

Este projeto foi desenvolvido como parte da formação *Alura Plus*, com foco na construção de uma interface web utilizando **HTML semântico e CSS moderno**.  
O principal objetivo foi transformar um layout em uma página funcional, organizada e responsiva, aplicando boas práticas front-end.

---

## 🚀 Tecnologias Utilizadas

- HTML5  
- CSS3

---

## 🎯 Habilidades Desenvolvidas

- Estruturação com **HTML semântico**  
- Estilização com **CSS moderno**  
- Aplicação de boas práticas de front-end  
- Organização visual de layout  
- Desenvolvimento responsivo

Este projeto demonstra minha capacidade de traduzir designs em páginas web funcionando com clareza, organização e responsividade.
